# HOW TO WRITE A NEW POST
# 1. Copy this file into the same folder (src/posts/).
#    Name the copy after the post, lowercase with dashes:
#    my-new-post.md  →  the post lives at /thinking/my-new-post
#    (Files starting with "_" like this one are never published.)
# 2. Fill in the lines below. Keep the quotes around text.
# 3. Write the post under the second "---" line.
# 4. Save and upload. The site rebuilds in about a minute.
#    If something is wrong (for example a misspelled pillar), the upload
#    is refused and the live site simply stays as it was.

# The big headline. A full sentence, ending with a period.
title: "Write the one-sentence point of the post."

# Exactly one of: People systems · Judgment calls · Building with AI
pillar: People systems

# One sentence shown under the title on the Thinking page and the home page.
tension: "The tension the post resolves, in one sentence."

# Publication date: year-month-day. The newest post is listed first.
date: 2026-10-09

# "draft" keeps it hidden on the live site. Change to "published" to go live.
status: draft

# Optional — delete any of these three lines you don't need:
# a shorter title for the browser tab (default: the headline without its final period)
pageTitle: "Short title"
# the text Google and LinkedIn show (default: the tension line)
description: "One or two sentences, under 160 characters."
# the writing pattern shown beside the post
pattern: Tension → Mechanism → Implication

Start with the point. One paragraph per idea; leave an empty line between paragraphs.

**Bold a short phrase** by putting two stars on each side.

US spelling (behavior, recognize, program). Use “curly quotes” and the long dash — like this.

> End on one short line, starting with ">". It becomes the closing statement with the amber line.
