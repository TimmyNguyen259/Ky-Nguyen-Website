# HOW TO WRITE A NEW POST
# 1. Copy this file into the same folder (src/posts/). Name the copy with
#    lowercase a–z (no accents), digits and dashes, ending in .md:
#    tu-duy-he-thong.md  →  the post lives at /thinking/tu-duy-he-thong
#    On github.com, type the ".md" yourself. Files starting with "_" (like
#    this one) are never published.
# 2. Fill in the lines below. Keep the straight quotes "…" around text —
#    without them a # cuts the line short and a : stops the upload.
#    Curly quotes “…” go only inside the text and in the post body.
# 3. Delete the sample text under the second "---" line and write your post there.
# 4. Save and commit. Within a minute or two a small mark appears next to
#    your change on GitHub: yellow ● = building, green ✓ = live,
#    red ✗ = the site was NOT updated. The old version stays online, and
#    nothing else (other posts included) goes live until this file is fixed.
#    Click ✗ → Details to read which line is wrong, then fix this same file
#    (don't upload a renamed copy) and commit again. This applies to drafts too.
#
# IF THE SITE DOESN'T UPDATE — what the error usually means:
#  • "mapping", "indentation" or "key" → a quote or colon problem on a text line
#    near the line number: each text needs one " at the start and one at the
#    end, with no " in between (use “ ” inside instead).
#  • "title: Required" although the title is there → the second --- line is
#    missing or mistyped.
#  • "Unrecognized key" → a line name is misspelled (e.g. Status instead of status).
